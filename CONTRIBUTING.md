# Contributing to Multimodal AI Fact-Checking

Thank you for contributing to the Multimodal Fact-Checking & Deepfake Detection project!

## Development Setup
1. Fork & clone the repository:
   \\\ash
   git clone https://github.com/your-username/multimodal-ai-fact-checking.git
   \\\
2. Install dependencies:
   \\\ash
   pip install -r backend/requirements.txt
   \\\
3. Run tests:
   \\\ash
   pytest backend/tests/
   \\\
4. Submit PR against \master\.
